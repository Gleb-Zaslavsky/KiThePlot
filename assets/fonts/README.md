# Bundled chart fonts

The three bundled font files are variable TrueType builds from the Noto Latin, Greek, and Cyrillic families. They are embedded so the built-in Sans Serif, Serif, and Monospace chart choices produce portable output with Cyrillic glyph coverage.

- [Noto Sans](https://github.com/google/fonts/tree/main/ofl/notosans)
- [Noto Serif](https://github.com/google/fonts/tree/main/ofl/notoserif)
- [Noto Sans Mono](https://github.com/google/fonts/tree/main/ofl/notosansmono)
